## اصطلاحات التوثيق

**مراجع الملفات**: تفاصيل التنفيذ تشير إلى ملفات المصدر كـ `path/to/file.cpp:line`

**تكامل الكود**: جميع التغييرات موسومة بـ `#ifdef ENABLE_POCX`

**المراجع التبادلية**: الفصول ترتبط بالأقسام ذات الصلة باستخدام روابط markdown نسبية

**المستوى التقني**: يفترض التوثيق الإلمام بـ Bitcoin Core وتطوير C++

## البناء

### بناء التطوير

```bash
# استنساخ مع الوحدات الفرعية
git clone --recursive https://github.com/PoC-Consortium/bitcoin-pocx.git
cd bitcoin-pocx/bitcoin

# Configure
cmake -B build

# البناء
cmake --build build -j$(nproc)
```

**متغيرات البناء**:
```bash
# مع واجهة Qt
cmake -B build -DBUILD_GUI=ON

# بناء التصحيح
cmake -B build -DCMAKE_BUILD_TYPE=Debug
```

**التبعيات**: تبعيات بناء Bitcoin Core القياسية. راجع [توثيق بناء Bitcoin Core](https://github.com/bitcoin/bitcoin/tree/master/doc#building) للمتطلبات الخاصة بكل منصة.

### بنية الإصدار

للحصول على ثنائيات إصدار قابلة للتكرار، استخدم نظام بناء GUIX: راجع [bitcoin/contrib/guix/README.md](../bitcoin/contrib/guix/README.md)
