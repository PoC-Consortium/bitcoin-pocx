## نظرة عامة

### ميزات محفظة Bitcoin-PoCX

توفر محفظة Bitcoin-PoCX Qt (`bitcoin-qt`):
- وظائف محفظة Bitcoin Core القياسية (إرسال، استلام، إدارة المعاملات)
- **مدير تعيين الصياغة**: واجهة رسومية لإنشاء/إلغاء تعيينات الرسم
- **وضع خادم التعدين**: علم `` يُفعّل الميزات المتعلقة بالتعدين
- **سجل المعاملات**: عرض معاملات التعيين والإلغاء

### تشغيل المحفظة

**العقدة فقط** (بدون تعدين):
```bash
./build/bin/bitcoin-qt
```

**مع التعدين** (يُفعّل حوار التعيين):
```bash
./build/bin/bitcoin-qt -server
```

**بديل سطر الأوامر**:
```bash
./build/bin/bitcoind
```

### متطلبات التعدين

**لعمليات التعدين**:
- علم `` مطلوب
- محفظة بعناوين P2WPKH ومفاتيح خاصة
- راسم خارجي (`pocx_plotter`) لتوليد الرسم
- مُعدّن خارجي (`pocx_miner`) للتعدين

**لتعدين المجمعات**:
- إنشاء تعيين صياغة لعنوان المجمع
- المحفظة غير مطلوبة على خادم المجمع (المجمع يدير المفاتيح)

## وحدات العملة

### عرض الوحدات

Bitcoin-PoCX يستخدم وحدة العملة **BTCX** (ليس BTC):

| الوحدة | ساتوشي | العرض |
|------|----------|---------|
| **BTCX** | 100000000 | 1.00000000 BTCX |
| **mBTCX** | 100000 | 1000.00 mBTCX |

**إعدادات الواجهة**: التفضيلات → العرض → الوحدة

## حوار تعيين الصياغة

### الوصول للحوار

**القائمة**: `المحفظة → تعيينات الصياغة`
**شريط الأدوات**: أيقونة التعدين (مرئية فقط مع علم ``)
**حجم النافذة**: 600×450 بكسل

### أوضاع الحوار

#### الوضع 1: إنشاء تعيين

**الغرض**: تفويض حقوق الصياغة لمجمع أو عنوان آخر مع الاحتفاظ بملكية الرسم.

**حالات الاستخدام**:
- تعدين المجمعات (التعيين لعنوان المجمع)
- التخزين البارد (مفتاح التعدين منفصل عن ملكية الرسم)
- البنية التحتية المشتركة (التفويض لمحفظة ساخنة)

**المتطلبات**:
- عنوان الرسم (P2WPKH bech32، يجب ملك المفتاح الخاص)
- عنوان الصياغة (P2WPKH bech32، مختلف عن عنوان الرسم)
- المحفظة مفتوحة (إذا مشفرة)
- عنوان الرسم يملك UTXOs مؤكدة

**الخطوات**:
1. اختر وضع "إنشاء تعيين"
2. اختر عنوان الرسم من القائمة المنسدلة أو أدخله يدوياً
3. أدخل عنوان الصياغة (المجمع أو المفوّض)
4. انقر "إرسال التعيين" (الزر مُفعّل عندما تكون المدخلات صالحة)
5. المعاملة تُبث فوراً
6. التعيين يصبح نشطاً بعد `nForgingAssignmentDelay` كتلة:
   - Mainnet/Testnet: 30 كتلة (~1 ساعة)
   - Regtest: 4 كتل (~4 ثوانٍ)

**رسوم المعاملة**: افتراضي 10× `minRelayFee` (قابل للتخصيص)

**هيكل المعاملة**:
- المدخل: UTXO من عنوان الرسم (يثبت الملكية)
- مخرج OP_RETURN: علامة `POCX` + plot_address + forging_address (46 بايت)
- مخرج التغيير: يُعاد للمحفظة

#### الوضع 2: إلغاء تعيين

**الغرض**: إلغاء تعيين الصياغة وإعادة الحقوق لمالك الرسم.

**المتطلبات**:
- عنوان الرسم (يجب ملك المفتاح الخاص)
- المحفظة مفتوحة (إذا مشفرة)
- عنوان الرسم يملك UTXOs مؤكدة

**الخطوات**:
1. اختر وضع "إلغاء تعيين"
2. اختر عنوان الرسم
3. انقر "إرسال الإلغاء"
4. المعاملة تُبث فوراً
5. الإلغاء يصبح فعالاً بعد `nForgingRevocationDelay` كتلة:
   - Mainnet/Testnet: 720 كتلة (~24 ساعة)
   - Regtest: 8 كتل (~8 ثوانٍ)

**التأثير**:
- عنوان الصياغة لا يزال يمكنه الصياغة خلال فترة التأخير
- مالك الرسم يستعيد الحقوق بعد اكتمال الإلغاء
- يمكن إنشاء تعيين جديد بعد ذلك

**هيكل المعاملة**:
- المدخل: UTXO من عنوان الرسم (يثبت الملكية)
- مخرج OP_RETURN: علامة `XCOP` + plot_address (26 بايت)
- مخرج التغيير: يُعاد للمحفظة

#### الوضع 3: فحص حالة التعيين

**الغرض**: استعلام حالة التعيين الحالية لأي عنوان رسم.

**المتطلبات**: لا شيء (للقراءة فقط، لا تتطلب محفظة)

**الخطوات**:
1. اختر وضع "فحص حالة التعيين"
2. أدخل عنوان الرسم
3. انقر "فحص الحالة"
4. صندوق الحالة يعرض الحالة الحالية مع التفاصيل

**مؤشرات الحالة** (مُرمّزة بالألوان):

**رمادي - UNASSIGNED**
```
غير مُعيّن - لا تعيين موجود
```

**برتقالي - ASSIGNING**
```
قيد التعيين - التعيين في انتظار التفعيل
عنوان الصياغة: pocx1qforger...
أُنشئ عند الارتفاع: 12000
يُفعّل عند الارتفاع: 12030 (5 كتل متبقية)
```

**أخضر - ASSIGNED**
```
مُعيّن - تعيين نشط
عنوان الصياغة: pocx1qforger...
أُنشئ عند الارتفاع: 12000
فُعّل عند الارتفاع: 12030
```

**برتقالي-أحمر - REVOKING**
```
قيد الإلغاء - الإلغاء معلق
عنوان الصياغة: pocx1qforger... (لا يزال نشطاً)
التعيين أُنشئ عند الارتفاع: 12000
أُلغي عند الارتفاع: 12300
الإلغاء يصبح فعالاً عند الارتفاع: 13020 (50 كتلة متبقية)
```

**أحمر - REVOKED**
```
مُلغى - التعيين أُلغي
كان مُعيّناً سابقاً لـ: pocx1qforger...
التعيين أُنشئ عند الارتفاع: 12000
أُلغي عند الارتفاع: 12300
الإلغاء فعال عند الارتفاع: 13020
```

## سجل المعاملات

### عرض معاملة التعيين

**النوع**: "تعيين"
**الأيقونة**: أيقونة التعدين (نفس الكتل المُعدّنة)

**عمود العنوان**: عنوان الرسم (العنوان الذي تُعيّن حقوق صياغته)
**عمود المبلغ**: رسوم المعاملة (سالب، معاملة صادرة)
**عمود الحالة**: عدد التأكيدات (0-6+)

**التفاصيل** (عند النقر):
- معرف المعاملة
- عنوان الرسم
- عنوان الصياغة (مُحلل من OP_RETURN)
- أُنشئ عند الارتفاع
- ارتفاع التفعيل
- رسوم المعاملة
- الطابع الزمني

### عرض معاملة الإلغاء

**النوع**: "إلغاء"
**الأيقونة**: أيقونة التعدين

**عمود العنوان**: عنوان الرسم
**عمود المبلغ**: رسوم المعاملة (سالب)
**عمود الحالة**: عدد التأكيدات

**التفاصيل** (عند النقر):
- معرف المعاملة
- عنوان الرسم
- أُلغي عند الارتفاع
- ارتفاع الإلغاء الفعال
- رسوم المعاملة
- الطابع الزمني

### تصفية المعاملات

**الفلاتر المتاحة**:
- "الكل" (افتراضي، يتضمن التعيينات/الإلغاءات)
- نطاق التاريخ
- نطاق المبلغ
- البحث بالعنوان
- البحث بمعرف المعاملة
- البحث بالتسمية (إذا كان العنوان مُسمّى)

**ملاحظة**: معاملات التعيين/الإلغاء تظهر حالياً تحت فلتر "الكل". فلتر نوع مخصص لم يُنفّذ بعد.

### فرز المعاملات

**ترتيب الفرز** (حسب النوع):
- مُولّد (النوع 0)
- مُستلم (النوع 1-3)
- تعيين (النوع 4)
- إلغاء (النوع 5)
- مُرسل (النوع 6+)

## متطلبات العنوان

### P2WPKH (SegWit v0) فقط

**عمليات الصياغة تتطلب**:
- عناوين مُشفّرة بـ Bech32 (تبدأ بـ "pocx1q" mainnet، "tpocx1q" testnet، "rpocx1q" regtest)
- صيغة P2WPKH (Pay-to-Witness-Public-Key-Hash)
- تجزئة مفتاح 20 بايت

**غير مدعوم**:
- P2PKH (قديم، يبدأ بـ "1")
- P2SH (SegWit ملفوف، يبدأ بـ "3")
- P2TR (Taproot، يبدأ بـ "bc1p")

**المبررات**: توقيعات كتل PoCX تتطلب صيغة witness v0 محددة للتحقق من الإثبات.

### تصفية القائمة المنسدلة للعناوين

**مربع اختيار عنوان الرسم**:
- يُملأ تلقائياً بعناوين الاستلام في المحفظة
- يُصفي العناوين غير P2WPKH
- يُظهر الصيغة: "التسمية (العنوان)" إذا مُسمّى، وإلا العنوان فقط
- العنصر الأول: "-- أدخل عنوان مخصص --" للإدخال اليدوي

**الإدخال اليدوي**:
- يتحقق من الصيغة عند الإدخال
- يجب أن يكون bech32 P2WPKH صالح
- الزر مُعطّل إذا كانت الصيغة غير صالحة

### رسائل خطأ التحقق

**أخطاء الحوار**:
- "Plot address must be segwit v0 (bech32)"
- "عنوان الصياغة يجب أن يكون P2WPKH (bech32)"
- "صيغة عنوان غير صالحة"
- "لا عملات متاحة عند عنوان الرسم. لا يمكن إثبات الملكية."
- "لا يمكن إنشاء معاملات مع محفظة للمشاهدة فقط"
- "المحفظة غير متاحة"
- "المحفظة مقفلة" (من RPC)

## تكامل التعدين

### متطلبات الإعداد

**تكوين العقدة**:
```bash
# bitcoin.conf
server=1
```

**متطلبات المحفظة**:
- عناوين P2WPKH لملكية الرسم
- مفاتيح خاصة للتعدين (أو عنوان الصياغة إذا كنت تستخدم تعيينات)
- UTXOs مؤكدة لإنشاء المعاملات

**الأدوات الخارجية**:
- `pocx_plotter`: توليد ملفات الرسم
- `pocx_miner`: مسح الرسومات وإرسال nonces

### سير العمل

#### التعدين الفردي

1. **توليد ملفات الرسم**:
   ```bash
   pocx_plotter --account <plot_address_hash160> --seed <32_bytes> --nonces <count>
   ```

2. **تشغيل العقدة** مع خادم التعدين:
   ```bash
   bitcoin-qt -server
   ```

3. **تكوين المُعدّن**:
   - الإشارة لنقطة نهاية RPC للعقدة
   - تحديد مجلدات ملفات الرسم
   - تكوين معرف الحساب (من عنوان الرسم)

4. **بدء التعدين**:
   ```bash
   pocx_miner --rpc-url http://localhost:8332 --plots /path/to/plots
   ```

5. **المراقبة**:
   - المُعدّن يستدعي `get_mining_info` كل كتلة
   - يمسح الرسومات لأفضل موعد نهائي
   - يستدعي `submit_nonce` عند إيجاد حل
   - العقدة تتحقق وتصيغ الكتلة تلقائياً

#### تعدين المجمعات

1. **توليد ملفات الرسم** (نفس التعدين الفردي)

2. **إنشاء تعيين صياغة**:
   - افتح حوار تعيين الصياغة
   - اختر عنوان الرسم
   - أدخل عنوان صياغة المجمع
   - انقر "إرسال التعيين"
   - انتظر تأخير التفعيل (30 كتلة testnet)

3. **تكوين المُعدّن**:
   - الإشارة لنقطة نهاية **المجمع** (ليس العقدة المحلية)
   - المجمع يتعامل مع `submit_nonce` للسلسلة

4. **تشغيل المجمع**:
   - محفظة المجمع تملك مفاتيح عنوان الصياغة الخاصة
   - المجمع يتحقق من إرسالات المُعدّنين
   - المجمع يستدعي `submit_nonce` لسلسلة الكتل
   - المجمع يوزع المكافآت وفق سياسة المجمع

### مكافآت Coinbase

**بدون تعيين**:
- Coinbase يدفع لعنوان مالك الرسم مباشرة
- تحقق من الرصيد في عنوان الرسم

**مع تعيين**:
- Coinbase يدفع لعنوان الصياغة
- المجمع يستلم المكافآت
- المُعدّن يستلم حصته من المجمع

**جدول المكافآت**:
- مبدئي: 10 BTCX لكل كتلة
- التنصيف: كل 1050000 كتلة (~4 سنوات)
- الجدول: 10 → 5 → 2.5 → 1.25 → ...

## استكشاف الأخطاء

### المشاكل الشائعة

#### "المحفظة لا تملك المفتاح الخاص لعنوان الرسم"

**السبب**: المحفظة لا تملك العنوان
**الحل**:
- استورد المفتاح الخاص عبر RPC `importprivkey`
- أو استخدم عنوان رسم مختلف تملكه المحفظة

#### "التعيين موجود بالفعل لهذا الرسم"

**السبب**: الرسم مُعيّن بالفعل لعنوان آخر
**الحل**:
1. ألغِ التعيين الموجود
2. انتظر تأخير الإلغاء (720 كتلة testnet)
3. أنشئ تعيين جديد

#### "صيغة العنوان غير مدعومة"

**السبب**: العنوان ليس P2WPKH bech32
**الحل**:
- استخدم عناوين تبدأ بـ "pocx1q" (mainnet) أو "tpocx1q" (testnet)
- أولّد عنوان جديد إذا لزم الأمر: `getnewaddress "" "bech32"`

#### "رسوم المعاملة منخفضة جداً"

**السبب**: ازدحام mempool الشبكة أو الرسوم منخفضة جداً للترحيل
**الحل**:
- زد معلمة معدل الرسوم
- انتظر تفريغ mempool

#### "التعيين لم يُفعّل بعد"

**السبب**: تأخير التفعيل لم ينقضِ بعد
**الحل**:
- افحص الحالة: الكتل المتبقية حتى التفعيل
- انتظر اكتمال فترة التأخير

#### "لا عملات متاحة عند عنوان الرسم"

**السبب**: عنوان الرسم لا يملك UTXOs مؤكدة
**الحل**:
1. أرسل أموال لعنوان الرسم
2. انتظر تأكيد 1
3. أعد محاولة إنشاء التعيين

#### "لا يمكن إنشاء معاملات مع محفظة للمشاهدة فقط"

**السبب**: المحفظة استوردت العنوان بدون المفتاح الخاص
**الحل**: استورد المفتاح الخاص الكامل، ليس العنوان فقط

#### "تبويب تعيين الصياغة غير مرئي"

**السبب**: العقدة بدأت بدون علم ``
**الحل**: أعد التشغيل مع `bitcoin-qt -server`

### خطوات التصحيح

1. **فحص حالة المحفظة**:
   ```bash
   bitcoin-cli getwalletinfo
   ```

2. **التحقق من ملكية العنوان**:
   ```bash
   bitcoin-cli getaddressinfo pocx1qplot...
   # تحقق: "iswatchonly": false, "ismine": true
   ```

3. **فحص حالة التعيين**:
   ```bash
   bitcoin-cli get_assignment pocx1qplot...
   ```

4. **عرض المعاملات الأخيرة**:
   ```bash
   bitcoin-cli listtransactions "*" 10
   ```

5. **فحص مزامنة العقدة**:
   ```bash
   bitcoin-cli getblockchaininfo
   # تحقق: blocks == headers (متزامن بالكامل)
   ```

## أفضل ممارسات الأمان

### أمان عنوان الرسم

**إدارة المفاتيح**:
- خزّن مفاتيح عنوان الرسم الخاصة بأمان
- معاملات التعيين تثبت الملكية عبر التوقيع
- فقط مالك الرسم يمكنه إنشاء/إلغاء التعيينات

**النسخ الاحتياطي**:
- انسخ المحفظة احتياطياً بانتظام (`dumpwallet` أو `backupwallet`)
- خزّن wallet.dat في موقع آمن
- سجّل عبارات الاسترداد إذا كنت تستخدم محفظة HD

### تفويض عنوان الصياغة

**النموذج الأمني**:
- عنوان الصياغة يستلم مكافآت الكتل
- عنوان الصياغة يمكنه توقيع الكتل (التعدين)
- عنوان الصياغة **لا يمكنه** تعديل أو إلغاء التعيين
- مالك الرسم يحتفظ بالتحكم الكامل

**حالات الاستخدام**:
- **تفويض المحفظة الساخنة**: مفتاح الرسم في تخزين بارد، مفتاح الصياغة في محفظة ساخنة للتعدين
- **تعدين المجمعات**: التفويض للمجمع، الاحتفاظ بملكية الرسم
- **البنية التحتية المشتركة**: مُعدّنون متعددون، عنوان صياغة واحد

### مزامنة وقت الشبكة

**الأهمية**:
- إجماع PoCX يتطلب وقت دقيق
- انحراف الساعة >10 ثوانٍ يُفعّل التحذير
- انحراف الساعة >15 ثانية يمنع التعدين

**الحل**:
- حافظ على مزامنة ساعة النظام مع NTP
- راقب: `bitcoin-cli getnetworkinfo` لتحذيرات إزاحة الوقت
- استخدم خوادم NTP موثوقة

### تأخيرات التعيين

**تأخير التفعيل** (30 كتلة testnet):
- يمنع إعادة التعيين السريعة أثناء تفرعات السلسلة
- يسمح للشبكة بالوصول للإجماع
- لا يمكن تجاوزه

**تأخير الإلغاء** (720 كتلة testnet):
- يوفر الاستقرار لمجمعات التعدين
- يمنع هجمات "التنقل بين التعيينات"
- عنوان الصياغة يبقى نشطاً أثناء التأخير

### تشفير المحفظة

**تفعيل التشفير**:
```bash
bitcoin-cli encryptwallet "your_passphrase"
```

**فتح للمعاملات**:
```bash
bitcoin-cli walletpassphrase "your_passphrase" 300
```

**أفضل الممارسات**:
- استخدم عبارة مرور قوية (20+ حرف)
- لا تخزن عبارة المرور كنص عادي
- أقفل المحفظة بعد إنشاء التعيينات
