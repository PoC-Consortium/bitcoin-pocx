## Про цю документацію

Це повна технічна документація для Bitcoin-PoCX — інтеграції з Bitcoin Core, що додає підтримку консенсусу Proof of Capacity наступного покоління (PoCX). Документація організована як посібник для перегляду з взаємопов'язаними розділами, що охоплюють усі аспекти системи.

**Цільова аудиторія**:
- **Оператори вузлів**: Розділи 1, 5, 6, 8
- **Майнери**: Розділи 2, 3, 7
- **Розробники**: Усі розділи
- **Дослідники**: Розділи 3, 4, 5

## Зміст

### Частина I: Основи

**[Розділ 1: Вступ та огляд](1-introduction.md)**
Огляд проекту, архітектура, філософія проектування, ключові особливості та відмінності PoCX від Proof of Work.

**[Розділ 2: Формат файлів плотів](2-plot-format.md)**
Повна специфікація формату плотів PoCX, включаючи оптимізацію SIMD, масштабування proof-of-work та еволюцію формату від POC1/POC2.

**[Розділ 3: Консенсус і майнінг](3-consensus-and-mining.md)**
Повна технічна специфікація механізму консенсусу PoCX: структура блоку, сигнатури генерації, налаштування базової цілі, процес майнінгу, конвеєр валідації та алгоритм Time Bending.

---

### Частина II: Розширені функції

**[Розділ 4: Система призначення кування](4-forging-assignments.md)**
Архітектура на основі OP_RETURN для делегування прав кування: структура транзакцій, проектування бази даних, скінченний автомат станів, обробка реорганізацій та інтерфейс RPC.

**[Розділ 5: Синхронізація часу та безпека](5-timing-security.md)**
Допуск дрейфу годинника, механізм захисного кування, захист від маніпуляцій з часом та питання безпеки, пов'язані з таймінгом.

**[Розділ 6: Параметри мережі](6-network-parameters.md)**
Конфігурація chainparams, блок генезису, параметри консенсусу, правила coinbase, динамічне масштабування та економічна модель.

---

### Частина III: Використання та інтеграція

**[Розділ 7: Довідник інтерфейсу RPC](7-rpc-reference.md)**
Повний довідник команд RPC для майнінгу, призначень та запитів до блокчейну. Необхідний для інтеграції майнерів і пулів.

**[Розділ 8: Посібник з гаманця та графічного інтерфейсу](8-wallet-guide.md)**
Посібник користувача для Qt-гаманця Bitcoin-PoCX: діалог призначення кування, історія транзакцій, налаштування майнінгу та усунення несправностей.

## Умовні позначення в документації

**Посилання на файли**: Деталі реалізації посилаються на вихідні файли як `шлях/до/файлу.cpp:рядок`

**Інтеграція коду**: Усі зміни позначені прапорцем `#ifdef ENABLE_POCX`

**Перехресні посилання**: Розділи посилаються на пов'язані секції за допомогою відносних посилань markdown

**Технічний рівень**: Документація передбачає знайомство з Bitcoin Core та розробкою на C++

## Збірка

### Збірка для розробки

```bash
# Клонування з підмодулями
git clone --recursive https://github.com/PoC-Consortium/bitcoin-pocx.git
cd bitcoin-pocx/bitcoin

# Configure
cmake -B build

# Збірка
cmake --build build -j$(nproc)
```

**Варіанти збірки**:
```bash
# З графічним інтерфейсом Qt
cmake -B build -DBUILD_GUI=ON

# Налагоджувальна збірка
cmake -B build -DCMAKE_BUILD_TYPE=Debug
```

**Залежності**: Стандартні залежності для збірки Bitcoin Core. Див. [документацію збірки Bitcoin Core](https://github.com/bitcoin/bitcoin/tree/master/doc#building) для вимог, специфічних для платформи.

### Релізні збірки

Для відтворюваних релізних бінарних файлів використовуйте систему збірки GUIX: Див. [bitcoin/contrib/guix/README.md](../bitcoin/contrib/guix/README.md)
