## О овој документацији

Ово је комплетна техничка документација за Bitcoin-PoCX, интеграцију у Bitcoin Core која додаје подршку за консензус заснован на Proof of Capacity нове генерације (PoCX). Документација је организована као водич који се може прегледати са међусобно повезаним поглављима која покривају све аспекте система.

**Циљне групе**:
- **Оператори чворова**: Поглавља 1, 5, 6, 8
- **Рудари**: Поглавља 2, 3, 7
- **Програмери**: Сва поглавља
- **Истраживачи**: Поглавља 3, 4, 5

## Конвенције документације

**Референце датотека**: Детаљи имплементације указују на изворне датотеке као `путања/до/датотеке.cpp:линија`

**Интеграција кода**: Све промене су означене са `#ifdef ENABLE_POCX`

**Унакрсне референце**: Поглавља се повезују на сродне секције користећи релативне markdown линкове

**Технички ниво**: Документација претпоставља познавање Bitcoin Core и C++ развоја

## Компајлирање

### Развојна верзија

```bash
# Клонирајте са подмодулима
git clone --recursive https://github.com/PoC-Consortium/bitcoin-pocx.git
cd bitcoin-pocx/bitcoin

# Configure
cmake -B build

# Компајлирајте
cmake --build build -j$(nproc)
```

**Варијанте компајлирања**:
```bash
# Са Qt графичким интерфејсом
cmake -B build -DBUILD_GUI=ON

# Debug верзија
cmake -B build -DCMAKE_BUILD_TYPE=Debug
```

**Зависности**: Стандардне зависности за компајлирање Bitcoin Core. Погледајте [документацију за компајлирање Bitcoin Core](https://github.com/bitcoin/bitcoin/tree/master/doc#building) за захтеве специфичне за платформу.

### Издања

За репродуцибилне бинарне датотеке издања, користите GUIX систем за компајлирање: Погледајте [bitcoin/contrib/guix/README.md](../bitcoin/contrib/guix/README.md)
