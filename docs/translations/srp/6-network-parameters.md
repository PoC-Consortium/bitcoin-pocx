## Параметри генезис блока

### Израчунавање базног циља

**Формула**: `genesis_base_target = 2^42 / block_time_seconds`

**Образложење**:
- Сваки nonce представља 256 KiB (64 бајта × 4096 scoop-ова)
- 1 TiB = 2^22 nonce-ова (претпоставка почетног капацитета мреже)
- Очекивани минимални квалитет за n nonce-ова ≈ 2^64 / n
- За 1 TiB: E(quality) = 2^64 / 2^22 = 2^42
- Дакле: base_target = 2^42 / block_time

**Израчунате вредности**:
- Mainnet/Testnet/Signet (120s): `36650387592`
- Regtest (120s): Користи режим калибрације ниског капацитета (base_power 2^58)

### Генезис порука

Each network has its own genesis message. See `src/kernel/chainparams.cpp` for details.

- **MAX_FUTURE_BLOCK_TIME**: `15` секунди

**Награде блокова**:
- **Почетна субвенција**: `10 BTC`

**Подешавање тежине**:
- **Клизни прозор**: `24` блока
- **Подешавање**: Сваки блок
- **Алгоритам**: Пондерисани покретни просек (Burstcoin стил, ограничење ±20% по блоку)

**Кашњења додељивања**:

## Параметри консензуса

### Параметри времена

**MAX_FUTURE_BLOCK_TIME**: `15` секунди
- PoCX-специфично (Bitcoin користи 2 сата)
- Образложење: PoC време захтева валидацију у скоро реалном времену
- Блокови више од 15s у будућности се одбијају

**Упозорење о временском офсету**: `10` секунди
- Оператери упозорени када сат чвора одступи >10s од мрежног времена
- Без примене, само информативно

**Циљеви времена блока**:
- Mainnet/Testnet/Signet: `120` секунди
- Regtest: `120` секунди

**TIMESTAMP_WINDOW**: `15` секунди (једнако MAX_FUTURE_BLOCK_TIME)

**Имплементација**: `src/chain.h`, `src/validation.cpp`

### Параметри подешавања тежине

**Величина клизног прозора**: `24` блока (све мреже)
- Пондерисани покретни просек недавних времена блокова (Burstcoin стил)
- Подешавање на сваком блоку
- Одзивно на промене капацитета

**Имплементација**: `src/consensus/params.h`, логика тежине у креирању блока

### Параметри система додељивања

**nForgingAssignmentDelay** (кашњење активације):
- Mainnet: `30` блокова (~1 сат)
- Testnet: `30` блокова (~1 сат)
- Regtest: `4` блока (~8 минута при размаку од 120s)

**nForgingRevocationDelay** (кашњење опозива):
- Mainnet: `720` блокова (~24 сата)
- Testnet: `720` блокова (~24 сата)
- Regtest: `8` блокова (~16 минута при размаку од 120s)

**Образложење**:
- Кашњење активације спречава брзо поновно додељивање током трка блокова
- Кашњење опозива обезбеђује стабилност и спречава злоупотребу

**Имплементација**: `src/consensus/params.h`

## Coinbase и награде блокова

### Распоред субвенције блокова

**Почетна субвенција**: `10 BTC` (све мреже)

**Распоред преполовљавања**:
- Сваких `1050000` блокова (mainnet/testnet)
- Сваких `500` блокова (regtest)
- Наставља се за максимално 64 преполовљавања

**Прогресија преполовљавања**:
```
Преполовљавање 0: 10.00000000 BTC  (блокови 0 - 1049999)
Преполовљавање 1:  5.00000000 BTC  (блокови 1050000 - 2099999)
Преполовљавање 2:  2.50000000 BTC  (блокови 2100000 - 3149999)
Преполовљавање 3:  1.25000000 BTC  (блокови 3150000 - 4199999)
...
```

**Укупна понуда**: ~21 милион BTC (исто као Bitcoin)

### Правила coinbase излаза

**Одредиште плаћања**:
- **Без додељивања**: Coinbase плаћа адреси плота (proof.account_id)
- **Са додељивањем**: Coinbase плаћа адреси ковања (ефективни потписник)

**Формат излаза**: Само P2WPKH
- Coinbase мора платити на bech32 SegWit v0 адресу
- Генерише се из јавног кључа ефективног потписника

**Разрешавање додељивања**:
```cpp
effective_signer = GetEffectiveSigner(plot_address, height, view);
coinbase_script = P2WPKH(effective_signer);
```

**Имплементација**: `src/pocx/mining/block_builder.cpp:BuildBlock()`

## Динамичко скалирање

### Границе скалирања

**Сврха**: Повећање тежине генерисања плота како мрежа сазрева да спречи инфлацију капацитета

**Структура**:
```cpp
struct PoCXCompressionBounds {
    uint32_t nPoCXMinCompression;     // Минимални прихваћен ниво
    uint32_t nPoCXTargetCompression;  // Препоручени ниво
};
```

**Однос**: `target = min + 1` (увек један ниво изнад минимума)

### Распоред повећања скалирања

Нивои скалирања се повећавају по **експоненцијалном распореду** заснованом на интервалима преполовљавања:

| Временски период | Висина блока | Преполовљавања | Min | Target |
|------------------|--------------|----------------|-----|--------|
| Године 0-4 | 0 до 1049999 | 0 | X1 | X2 |
| Године 4-12 | 1050000 до 3149999 | 1-2 | X2 | X3 |
| Године 12-28 | 3150000 до 7349999 | 3-6 | X3 | X4 |
| Године 28-60 | 7350000 до 15749999 | 7-14 | X4 | X5 |
| Године 60-124 | 15750000 до 32549999 | 15-30 | X5 | X6 |
| Године 124+ | 32550000+ | 31+ | X6 | X7 |

**Кључне висине** (године → преполовљавања → блокови):
- Година 4: Преполовљавање 1 на блоку 1050000
- Година 12: Преполовљавање 3 на блоку 3150000
- Година 28: Преполовљавање 7 на блоку 7350000
- Година 60: Преполовљавање 15 на блоку 15750000
- Година 124: Преполовљавање 31 на блоку 32550000

### Тежина нивоа скалирања

**PoW скалирање**:
- Ниво скалирања X0: POC2 основа (теоријски)
- Ниво скалирања X1: XOR-transpose основа
- Ниво скалирања Xn: 2^(n-1) × X1 рад уграђен
- Сваки ниво удвостручује рад генерисања плота

**Економско усклађивање**:
- Награде блокова се преполовљавају → тежина генерисања плота се повећава
- Одржава сигурносну маргину: трошак креирања плота > трошак претраживања
- Спречава инфлацију капацитета од побољшања хардвера

### Валидација плота

**Правила валидације**:
- Послати докази морају имати ниво скалирања ≥ минимум
- Докази са скалирањем > target се прихватају али су неефикасни
- Докази испод минимума: одбијени (недовољан PoW)

**Преузимање граница**:
```cpp
auto bounds = GetPoCXCompressionBounds(height, halving_interval);
```

**Имплементација**: `src/pocx/consensus/params.h:GetPoCXCompressionBounds()`, `src/pocx/consensus/params.cpp`

## Мрежна конфигурација

### Seed чворови и DNS seed-ови

**Статус**: Активно (главна мрежа активна од 3. маја 2026)

**DNS seed-ови главне мреже**:
- `seeds.bitcoin-pocx.org`
- `bitcoin-pocx.bootseed.net`

**DNS seed-ови тестне мреже**:
- `testnet.seeds.bitcoin-pocx.org`

**Конфигурација**:
- Фиксни seed-ови испоручени у `src/pocx/pocx_seeds.h` (BIP155 формат)
- Такође су подржане ручне конекције пирова преко `-addnode`

**Имплементација**: `src/kernel/chainparams.cpp`

### Checkpoint-ови

**Генезис checkpoint**: Увек блок 0

**Додатни checkpoint-ови**: Тренутно нису конфигурисани

**Будуће**: Checkpoint-ови ће бити додати како mainnet напредује

## Конфигурација P2P протокола

### Верзија протокола

**Основа**: Bitcoin Core v30.2 протокол
- **Верзија протокола**: Наслеђена од Bitcoin Core
- **Service bits**: Стандардни Bitcoin сервиси
- **Типови порука**: Стандардне Bitcoin P2P поруке

**PoCX проширења**:
- Заглавља блокова укључују PoCX-специфична поља
- Поруке блокова укључују PoCX податке доказа
- Правила валидације примењују PoCX консензус

**Компатибилност**: PoCX чворови некомпатибилни са Bitcoin PoW чворовима (различит консензус)

**Имплементација**: `src/protocol.h`, `src/net_processing.cpp`

## Структура директоријума података

### Подразумевани директоријум

**Локација**: `.bitcoin/` (исто као Bitcoin Core)
- Linux: `~/.bitcoin/`
- macOS: `~/Library/Application Support/Bitcoin/`
- Windows: `%APPDATA%\Bitcoin\`

### Садржај директоријума

```
.bitcoin/
├── blocks/              # Подаци блокова
│   ├── blk*.dat        # Датотеке блокова
│   ├── rev*.dat        # Подаци за поништавање
│   └── index/          # Индекс блокова (LevelDB)
├── chainstate/         # UTXO скуп + додељивања ковања (LevelDB)
├── wallets/            # Датотеке новчаника
│   └── wallet.dat      # Подразумевани новчаник
├── bitcoin.conf        # Конфигурациона датотека
├── debug.log           # Debug лог
├── peers.dat           # Адресе пирова
├── mempool.dat         # Трајни mempool
└── banlist.dat         # Банирани пирови
```

### Кључне разлике од Bitcoin-а

**Chainstate база података**:
- Стандардно: UTXO скуп
- **PoCX додатак**: Стање додељивања ковања
- Атомска ажурирања: UTXO + додељивања ажурирана заједно
- Подаци за поништавање безбедни за реорг за додељивања

**Датотеке блокова**:
- Стандардни Bitcoin формат блока
- **PoCX додатак**: Проширен PoCX пољима доказа (account_id, seed, nonce, signature, pubkey)

### Пример конфигурационе датотеке

**bitcoin.conf**:
```ini
# Селекција мреже
#testnet=1
#regtest=1

# PoCX сервер за рударење (потребан за спољне рударе)

# RPC подешавања
server=1
rpcuser=yourusername
rpcpassword=yourpassword
rpcallowip=127.0.0.1
rpcport=8332

# Подешавања конекције
listen=1
port=8338
maxconnections=125

# Циљано време блока (информативно, примењује консензус)
# 120 секунди за mainnet/testnet
```
