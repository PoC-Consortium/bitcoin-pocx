## इस दस्तावेज़ीकरण के बारे में

यह Bitcoin-PoCX का संपूर्ण तकनीकी दस्तावेज़ीकरण है, जो Bitcoin Core में Proof of Capacity neXt generation (PoCX) सहमति समर्थन जोड़ने वाला एक एकीकरण है। दस्तावेज़ीकरण को आपस में जुड़े अध्यायों वाले एक ब्राउज़ करने योग्य गाइड के रूप में व्यवस्थित किया गया है जो सिस्टम के सभी पहलुओं को कवर करता है।

**लक्षित दर्शक**:
- **नोड संचालक**: अध्याय 1, 5, 6, 8
- **माइनर**: अध्याय 2, 3, 7
- **डेवलपर**: सभी अध्याय
- **शोधकर्ता**: अध्याय 3, 4, 5

## दस्तावेज़ीकरण परंपराएं

**फ़ाइल संदर्भ**: कार्यान्वयन विवरण स्रोत फ़ाइलों को `path/to/file.cpp:line` के रूप में संदर्भित करते हैं

**कोड एकीकरण**: सभी परिवर्तन `#ifdef ENABLE_POCX` के साथ फ़ीचर-फ़्लैग किए गए हैं

**क्रॉस-रेफरेंस**: अध्याय सापेक्ष markdown लिंक का उपयोग करके संबंधित अनुभागों से लिंक करते हैं

**तकनीकी स्तर**: दस्तावेज़ीकरण Bitcoin Core और C++ विकास से परिचितता मानता है

## बिल्डिंग

### डेवलपमेंट बिल्ड

```bash
# सबमॉड्यूल के साथ क्लोन करें
git clone --recursive https://github.com/PoC-Consortium/bitcoin-pocx.git
cd bitcoin-pocx/bitcoin

# Configure
cmake -B build

# बिल्ड करें
cmake --build build -j$(nproc)
```

**बिल्ड वेरिएंट**:
```bash
# Qt GUI के साथ
cmake -B build -DBUILD_GUI=ON

# डीबग बिल्ड
cmake -B build -DCMAKE_BUILD_TYPE=Debug
```

**निर्भरताएं**: मानक Bitcoin Core बिल्ड निर्भरताएं। प्लेटफ़ॉर्म-विशिष्ट आवश्यकताओं के लिए [Bitcoin Core बिल्ड दस्तावेज़ीकरण](https://github.com/bitcoin/bitcoin/tree/master/doc#building) देखें।

### रिलीज़ बिल्ड

पुनरुत्पादनीय रिलीज़ बाइनरी के लिए, GUIX बिल्ड सिस्टम का उपयोग करें: [bitcoin/contrib/guix/README.md](../bitcoin/contrib/guix/README.md) देखें

## इस दस्तावेज़ीकरण को कैसे पढ़ें

**क्रमिक पठन**: अध्याय क्रम में पढ़ने के लिए डिज़ाइन किए गए हैं, पिछली अवधारणाओं पर निर्माण करते हुए।

**संदर्भ पठन**: विशिष्ट विषयों पर सीधे जाने के लिए विषय-सूची का उपयोग करें। प्रत्येक अध्याय संबंधित सामग्री के क्रॉस-रेफरेंस के साथ स्व-निहित है।

**ब्राउज़र नेविगेशन**: markdown व्यूअर या ब्राउज़र में `index.md` खोलें। सभी आंतरिक लिंक सापेक्ष हैं और ऑफ़लाइन काम करते हैं।

**PDF निर्यात**: इस दस्तावेज़ीकरण को ऑफ़लाइन पढ़ने के लिए एक PDF में संयोजित किया जा सकता है।

## योगदान

दस्तावेज़ीकरण में योगदान का स्वागत है। कृपया बनाए रखें:
